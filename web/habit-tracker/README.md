This is a minimal habit tracker with a black and white aesthetic. This is because in the future I will use this habit tracker in a e-ink display.

## Features

-**Streak counter** tracks consecutive days. A day only counts toward the strak if **all** the habits are completed
- **Consistency grid** Github-style contribution graph covering the last 26 weeks. Each cell warkens according to how many habits were completed that day.
- **Weekly progress** per-habit progress bars showing completitions out of the weekly target.
- **Two views** 'Hábitos' for daily check-off, 'COnstancia' for stats and history.
